# 音響設計

V2現状品質版の設計と現行検証の入口。具体的な式・係数・周波数・ゲインの正本は
[数学モデル](mathematical-model.md)。過去の試聴判断と現行の数値測定を混同しない。

## 聴感の基準

規則的な反復の中で強弱、接触音、尾長、定位、残響、長周期輪郭を変える。
短い有限発音と声部の重なりで連続性を作る。低い持続音、強すぎる高域、硬いクリック、
理由のない長い無音を避ける。共通の丸い中域を保ちながら隣接章を3軸以上で区別する。

共有ピコ7章では、係数由来の知覚強度が初期部分音の接触量へ写る。
部分音の減衰時間を章別にし、石英、波紋、弦、残火、雨、帳、軌道に対応する触感を作る。
この接触量を局所発光・線の立ち上がりにも使う。数学的係数と知覚補正後ゲインを区別する。

Besselでは係数の立方根圧縮により強拍だけへの集中を抑える。
Riemannでは平方数主時刻を保ち、混み合う発音間隔に応じた知覚ゲインを使う。
Lissajous、Prime、Riemannのpanは表示と同じ絶対数学位相から連続評価する。
Cathedralの専用DSPは、弱い第2部分音が先に減衰する石英の接触と、205〜340 msの
有限尾へ更新した。係数の0.6乗圧縮で強いモードへの集中を減らし、モード変位・速度から
減衰と接触時間を決める。柱の局所impactは同じ発音包絡を使う。
Möbiusは27〜50 msの丸い立ち上がり、330〜490 msの有限尾、2〜3部分音の
母音を模した音色変化へ更新した。現在のモード変位と速度が振幅・定位・部分音重みへ作用し、
帯上の局所光も同じ包絡と部分音比を使う。
Residueは270〜340 msの有限尾を2声まで重ね、5倍以上の調波が45 msで先に薄れる接触へ更新した。
18.7〜24.2 msの立ち上がりとaccentの0.75乗圧縮で輪郭を丸め、局所コロナも同じ包絡・接触量を使う。
carrierごとの定常1極応答を包絡の前に掛けるため、内部IIRの履歴なしでseekを再構成できる。
全章の最終QAと、更新したResidueのブラウザ観察は継続中。

## 回帰条件

- 8 kHzの決定的な未マスターdry全周期stereo RMSを0.023、許容差±0.05 dBへ校正する。
- これは章間基準ゲインの指標であり、EQ・残響後の知覚音量や幕内の静動を同一化しない。
- 生成キャリアは左右デチューン、chirp両端、位相ドリフト後に0.45 Fs未満。帯域外部分音だけを省く。
- 有限包絡のスペクトルは厳密な帯域有限ではない。上の条件を全音声スペクトルの無漏れと説明しない。
- TypeScript参照DSPとWorkletの標本一致を確認する。Workletは48 kHz・128標本でp95 1.333 ms未満を目標とする。
- EQ・limiter・残響を含むグラフは初期音量35%、最終ピーク原則−1 dBFS以下を保つ。
