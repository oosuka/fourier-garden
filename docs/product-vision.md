# 作品の方針

現行の制作方針。V2の完成宣言ではない。

数学を見せるだけでなく、観察し、聴き、美しさから理解へ進める作品を作る。
同じ数学的原因から音と光が立ち上がり、単独よりも同時体験で意味が増すことを目指す。
正しい数学を土台に、時間、素材、距離、密度、余白を設計する。

## 品質の判断

数学的正確性を優先する。その範囲で、章固有性、長時間の発見、音の心地よさ、
繊細なグラフィック、精密な同期、レスポンス、デスクトップChromeの安定性を追求する。
数学そのものが静かでも、観察視点と局所応答によって鑑賞価値を作る。

有限和・境界・係数を表示する数学層と、聴覚へ変換する音、詩的な造形を区別する。
見栄えのために数学値を変えず、変換の意味を観察ノートからたどれるようにする。

入口は短く、音と光の最初の瞬間をそろえる。操作は必要なときに現れ、数学を読む間も
映像を観察できる。音なし、キーボード、reduced motionを含め、選択を尊重する。

## 制作範囲

全10章のアート、音、数学、UX、遷移、同期、アーキテクチャ、文書、QAを対象とする。
アカウントや通信、機能数を増やすことは目的にしない。
旧版の色、粒子数、UI配置は維持目標ではない。現在の判断は
[V2設計](superpowers/specs/2026-09-06-renewal-design.md)に集約する。
