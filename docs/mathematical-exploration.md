# 観察ノートの数学実験

各章の「やさしい説明」に、値を動かして比較する小さな図を置く。
この図の操作は本編の数学、スコア、音声を変更しない。比較で変える量を明記し、
元の係数を選択後に勝手に再正規化しない。軸の範囲は操作中も固定する。

| 章 | 変える量 | 観察するもの |
| --- | --- | --- |
| Residue | 先頭1〜13項 | 振幅5/(k+1)を保った部分和と全13項の比較 |
| Cathedral | 本編の12固有モード | 長方形の節線。内側の線はx=jπ/m、y=kπ/(√2n) |
| Prime | 小さい順に1〜25素数 | 各係数1/25の有限指数和の複素平面上の軌跡 |
| Möbius | λ≤13の候補(m,n) | sin(mx)とsin(m(π−x))cos(nπ)の継ぎ目比較 |
| Bessel | 本編の17固有モード | Bessel零点比による節円、正弦／余弦の節径 |
| Lissajous | 2:3曲線の相対位相δ | 整数比を保ったまま変わる平面形状 |
| Dirichlet | 奇数の最高次数1〜63 | 矩形波の部分和と同じ次数のFejér平均 |
| Haar | J=0〜6 | 各区間の解析的平均による2ᴶ区間の射影 |
| Riemann | 12、24、48、96項 | x∈[−0.12,0.12]を拡大した有限部分和 |
| Torus | 1、3/2、7/5、√2の速度比 | 横の角度が10周する間のT²のパラメータ図 |

Möbiusの候補図は係数を1、時刻を0にして比べる。m+nが偶数の候補は本編に追加せず、
継ぎ目で符号が逆になることを示す。BesselとCathedralの図は単独モードの空間的な節であり、
合成面の節や時刻による全体の零点とは呼ばない。Torusの反対辺は同一視されるが、
辺をまたぐ標本を対角線で結ばない。有限の図から無理性や無限時間の稠密性を判定しない。

SVGの曲線は解析式で評価した有限標本を結ぶ数値描画である。Haarは半開区間ごとの
水平線を独立に描き、不連続点に存在しない縦の線を作らない。
図に表示する座標と、音声や詩的造形のパラメータを混同しない。

実験の定義と計算は各章の`study.ts`が所有し、既存の純粋数学関数を使う。
共有契約は`src/experience/mathematicalStudy.ts`、表示は`MathematicalStudy.tsx`。
アニメーションのためのReact更新は行わず、操作時だけ再計算する。
スライダーはラベル、現在値の読み上げ、矢印キー、Home／End、リセット操作を持つ。
実験値は章ごとに鑑賞セッション内で保持する。ノートの開閉、説明タブの切替、
別章への往復で比較をやり直す必要はない。「初めの値」でその章の基準値へ戻り、
ページを再読み込みすると全章の実験値は初期化される。ブラウザへの永続保存は行わない。
説明タブまたは章を切り替えると、新しい説明の先頭から表示する。
同じ説明の通常更新では、読んでいるスクロール位置を維持する。
