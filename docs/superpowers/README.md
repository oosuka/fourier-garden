# Superpowers履歴索引

このディレクトリには、2026年6月の試行錯誤で作成した詳細な設計書と実装計画が
置かれていた。Chapter 1から3の音響仕様は2026年7月2日に整理し、2026年7月11日の
シネマティック描画・音響刷新、最終音色評価、QAと、その後のレビュー修正を経た
2026年7月12日の正式版では、現行正本を次の文書へ集約した。

- 開発時の不変条件: [`../../AGENTS.md`](../../AGENTS.md)
- 実装済み章の数理・音響正本: [`../mathematical-model.md`](../mathematical-model.md)
- 章比較と将来章入口条件: [`../chapter-atlas.md`](../chapter-atlas.md)
- QA履歴と運用QA項目: [`../../design-qa.md`](../../design-qa.md)
- 利用者向け概要: [`../../README.md`](../../README.md)

削除した詳細計画には、現行の正式版音響・描画仕様と矛盾する廃止済み仕様が含まれていた。
それらは履歴資料であり、実装時の参照先にしてはならない。現在の実装判断は、
上記の正本文書だけを参照する。

現行の全10章音響は、丸い中域ピコ文法と全周期dry bus RMS `0.023 ±0.05 dB`を共有する。
Chapter 1は13調波の支持を維持しながら上側調波と残響を抑え、Chapter 2から10は
局所モチーフへ全周期の長周期輪郭を重ねる。強弱、尾長、wet、連続定位を別位相で変え、
数学支持、係数比、符号位相、絶対数学時刻は変更しない。過去資料の4 slot反復だけの
音響仕様と章間の広いRMS許容幅は廃止済みである。
