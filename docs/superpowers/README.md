# Superpowers履歴索引

このディレクトリには、2026年6月の試行錯誤で作成した詳細な設計書と実装計画が
置かれていた。Chapter 1から3の音響仕様は2026年7月2日に整理し、現行正本を
次の文書へ集約した。

- 開発時の不変条件: [`../../AGENTS.md`](../../AGENTS.md)
- 実装済み章の数理・音響正本: [`../mathematical-model.md`](../mathematical-model.md)
- 章比較と将来章入口条件: [`../chapter-atlas.md`](../chapter-atlas.md)
- QA履歴と未確認事項: [`../../design-qa.md`](../../design-qa.md)
- 利用者向け概要: [`../../README.md`](../../README.md)

削除した詳細計画には、Chapter 2の95イベント鐘状音、Chapter 3の63/72/78/90イベント、
母音状合唱、breath、複数mora、複数部分音など、現行v16音響と矛盾する仕様が含まれていた。
それらは履歴資料であり、実装時の参照先にしてはならない。

現行の公開音響は、Chapter 1から3で参照動画寄りの一定16分ピコ時計を共有し、
各章の数学量を420-980 Hzまたは420-920 Hzの安全な中域へ写す方針で固定する。
Chapter 1は花弁状の4音強弱、Chapter 2は乾いた格子、Chapter 3は左右へ流れる帯として
分離し、旧計画の高域鐘・合唱・息成分へ戻さない。
