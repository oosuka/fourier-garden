# Superpowers履歴索引

置かれていた。Chapter 1から3の音響仕様は2026年7月2日に整理し、現行正本を
次の文書へ集約した。

- 実装済み章の数理・音響正本: [`../mathematical-model.md`](../mathematical-model.md)

削除した詳細計画には、現行v18音響と矛盾する廃止済み仕様が含まれていた。
それらは履歴資料であり、実装時の参照先にしてはならない。現在の実装判断は、
上記の正本文書だけを参照する。

現行の公開音響は、Chapter 1から3で参照動画寄りの一定16分ピコ時計を共有し、
各章の数学量を420-980 Hzまたは420-920 Hzの安全な中域へ写す方針で固定する。
Chapter 1はsection別4音強弱、小節ローテーション、16ステップのゴースト輪郭、
明度と余韻の強弱写像、Chapter 2は乾いた格子、Chapter 3は左右へ流れる帯として分離し、
単一部分音、短い有限包絡、高域抑制、明確な章別リズムキャラクターを維持する。
