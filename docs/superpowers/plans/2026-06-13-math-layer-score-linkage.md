# 数学線と音楽の視覚連動 実装記録

> **状態:** 実装・自動検証・ブラウザQAまで完了した履歴資料である。
> 音響と反復スコアの現在の制約は、後続の
> [`2026-06-13-mathematical-integrity-hardening.md`](2026-06-13-mathematical-integrity-hardening.md)
> を正とする。

**目的:** 厳密なエピサイクル、フェーザ終点、主履歴波形を変形せず、
共有48小節スコアの発音を左側の調波コロナと右側の履歴パルスとして
初見でも認識できる強さで重ねる。

**構成:** `MusicalScoreFrame`から発光強度だけを純粋関数で導く。左側には
13個の厳密円と同じ座標・倍率を持つ別ライン、右側には主波形と同じ射影式で
計算する短い別ラインを詩的造形層として追加する。

**技術要素:** TypeScript 6、React 19、Three.js r184を使用する。
描画と検証にはWebGPURenderer、WebGLRenderer、Vitest、Biome、Oxlintを使用する。

## 維持した不変条件

- \(f(x)=5\sum_{k=0}^{12}(k+1)^{-1}\sin((4k+1)x)\)
- \(n_k=4k+1\)、\(A_k=5/(k+1)\)、\(x(t)=0.31t\)
- 13円、14点のスポーク、フェーザ終点、主波形の座標・倍率・位相
- 音響の基礎知覚重み\(A_k/(k+1)^{1.4}\)
- 左右デチューン後の帯域条件
  \(\max(n_k\nu_j(1-d),n_k\nu_j(1+d))<0.45F_s\)
- 数学線と詩的な発光線を別オブジェクトとして管理する
- フレームごとにGPUオブジェクトや配列を生成しない
