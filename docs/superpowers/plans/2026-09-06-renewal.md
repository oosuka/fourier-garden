# Fourier Garden V2 実装計画

> 実行: superpowers:executing-plansに従い、このセッションで段階ごとに実装・検証する。
> 利用者は調査後の継続実装を明示している。メイン実装は単一エージェントで行う。

**目標:** 数学から音と光が同時に立ち上がる全10章の鑑賞体験を再構築する。

**構成:** 章の数学とスコアは正本を維持する。共通開始epochと出力時計、楽譜由来の
局所応答、章別の素材・空間、観察UIを順に統合する。

**技術:** React 19、TypeScript 7、Three.js r185、Web Audio、Vitest、Vite 8。

**進捗・検証証拠:** [作業記録](../../qa/renewal/progress.md)（2026年9月14日更新、全体は制作中）

**設計:** [V2設計](../specs/2026-09-06-renewal-design.md)

## 共通条件

- Node.js 24.19.0、npm 11.19.0、依存追加なし。
- 数学時刻は絶対時刻。装飾を数学値と呼ばない。
- 全生成周波数は左右デチューンとchirp後に0.45 Fs未満。
- 全周期dry RMS 0.023 ±0.05 dBを校正・比較する。
- 各段階で`rtk proxy npm run typecheck`、`lint`、関連テスト、`build`とブラウザを検証する。
- 要求のないコミット、プッシュ、公開をしない。

絶対時刻のフェーザを保持する。音響処理の尾と数学の時間を分離する。

- [x] ノート併用時の切れと装飾のreduced motion漏れを実画面で再現する。
- [x] 係数の絶対和から円鎖の全時刻上界を求め、波形と共通倍率で画面へ収める。
- [x] 装飾の基本運動と瞬間的な励起を分け、長時間の位置跳びを抑える。
- [x] 両rendererで修正後の構図・背景固定・数学の継続を確認する。
- [x] 次の格子で切り替わる短音を、260〜340 msを目安とした有限の重なりへ更新する。
  弱い高次倍音は初期接触から早く減衰させ、基音の丸い尾を保つ。実波形を見て値を決める。
  2声の固定プールで隣接発音を保持する。色付けの1 pole応答は各carrierの定常利得・位相として
  事前計算し、その後に有限包絡を掛ける。filterの履歴に依存せずseekを再構成する。
  源係数を保持し、知覚重みとaccentの圧縮を別のソニフィケーションとして記す。
