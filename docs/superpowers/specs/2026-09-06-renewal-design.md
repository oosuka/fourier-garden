# Fourier Garden V2 設計

本書は2026年9月6日の全面リニューアル依頼に対する現行設計である。旧版の音色数値や
QA判定を永続的な設計制約とはしない。数学的対象、明示的な安全条件、実測証拠は維持する。

## 現行監査と方針

V2開始時点で595件のテストが通る数学、決定的スコア、帯域制限、章別DSP、二つのrendererを保存する。
現在の検証数・実測・未検証範囲は[作業記録](../../qa/renewal/progress.md)を正とする。
一方、画面を横断する装飾線と均等な星塵が主形状と競合し、文字の多くが7–10pxに留まる。
開始はWorkletへのseek／activeとtransportの起動が独立し、出力遅延も補償していない。
章切替は160msの音声破棄と1.8秒の遮蔽へ依存する。章によって局所的な発音包絡が描画へ
渡らず、Besselの選択は絶対時刻の整数部から求められ、楽譜の周回境界で一致しない。

表層のみの改修、全DSPと数学の一括書き換え、検証済み数理核を保った体験再構築を比較し、
三つ目を採用する。描画、音響、インタラクションを共通の数学イベントから再構成する。

## 視覚

主題は「暗い空間に、数理現象が光の素材として立ち上がる庭」。墨に近い黒、暖かな白、
酸化金、深い緑を基調に、章別の冷暖と符号を使う。装飾は薄膜、刻線、局所の共鳴、
奥行きのある粒へ整理する。全画面の均等な星塵、虹色の多重線、汎用光柱を減らす。
大きさではなく、焦点の精度、暗部、局所の材質、近景と遠景の速度差を設計する。

| 章 | 主な素材・空間 | 発音の視覚的受け手 |
| --- | --- | --- |
| Residue Bloom | 金属糸の円鎖と絹の波形 | フェーザ節点と投影の残光 |
| Spectral Cathedral | 石英の波動面、縦の空洞 | 発音モードの節領域 |
| Prime Constellation | 琥珀の位相点、広い垂直空間 | 素数点から隣接リンクへの短い伝播 |
| Möbius Choir | 真珠の織布、一続きの反転する帯 | 対応モードの流動と継ぎ目 |
| Bessel Tide | 青磁の円板、同心の水膜 | 実際の発音モードの節円・節径・水滴 |
| Lissajous Orchard | 緑金の弦、奥行きのある果樹 | 句で選択された曲線と座標 |
| Dirichlet Lanterns | 火の芯と整った低い側葉 | 主発音／側葉応答を別の位置へ |
| Wavelet Rain | 墨と銀の支持区間、垂直の雨 | 発音係数のセルと支持中心 |
| Riemann Veil | 薄い銅の帳、積層した曲線 | 平方数支持と下行応答の別の余韻 |
| Phase Torus | 緑の陶磁の位相空間、軌道 | Fourier文字と現在の軌道点 |

## 音と光

規則的な有限発音と帯域制限を維持し、章固有のアタック、減衰、初期反射、音色の
長周期変化を再設計する。全周期dry RMS 0.023 ±0.05dBを比較基準として維持し、
変えた音響は校正し直す。高域刺激と連続性は決定的な代表レンダーと章間比較で判断する。
現実のスピーカーで人間が聴いたと偽って報告せず、利用者への追加試聴は要求しない。

音声へ渡すスコアのsourceIndex、絶対イベント時刻、有限包絡、連続panを視覚でも読む。
各章が局所座標へ写し、発光の立ち上がり、幅、余韻、鋭さへ展開する。
音量アナライザーは因果の入力にしない。厳密な座標や係数を演出用に変形しない。
スコアを二分探索し、前周回の尾も扱い、seek後も同じ絶対時刻から再現する。

AudioContext上の開始時刻を一つ決め、一つのstartメッセージでWorkletを予約する。
transportは同じepochを採用し、出力タイムスタンプで実際に聴こえる時刻へ合わせる。
遅れて届いたstartでも、到着時刻を開始時刻にしない。pause、resume、章変更、非表示、
長時間の時計をテストする。開始時は最初の描画完了後に音と光を共通epochで開く。

## 鑑賞と理解

入口は左に大きい二段のタイトル、右に作品そのものを置く。音の有無を選んで一度で入る。
鑑賞画面は余白、章名、必要な操作だけに整理する。全10章へ直接移れる章目録と、
現在の現象を短く読む観察表示を用意する。詳細は横へ空間を譲る読み物とし、
感覚→現象→定義→写像→深掘り→関連章の順に段階化する。
Space／D／Fを維持し、入力やボタン上のSpaceを奪わない。Escape、タブ操作、
focus復元、reduced motionを整える。音なしでも作品が進む。

## 文書・技術・完了判定

Node 24.19.0／npm 11.19.0、React、Three.js、Viteを維持する。依存を増やさない。
AGENTS.mdを短い地図へ整理し、数学、音響、視覚、因果、QA、性能を目的別文書へ分離する。
旧版の履歴は履歴として保存し、現行仕様と区別する。
各段階で型、lint、テスト、build、ブラウザの検証を行う。最後に全10章・複数時刻・
WebGPU／WebGL2・3アスペクト比、4Kの60秒計測、長時間の同期とリソース、音響の
代表レンダーを残す。自動テストと主観的な品質判断を区別し、残課題を隠さない。
