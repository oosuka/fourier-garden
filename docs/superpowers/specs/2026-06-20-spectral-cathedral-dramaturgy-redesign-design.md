# Spectral Cathedral 動勢再設計

## 文書の位置付け

- 作成日: 2026年6月20日
- 対象: Chapter 2 `Spectral Cathedral / スペクトルの聖堂`
- 状態: 2026年6月20日に実装・自動検証・ブラウザQAまで完了した現行仕様
- 優先順位: 本文書より`AGENTS.md`と`docs/mathematical-model.md`の数学的不変条件を優先する

本設計は、厳密数学層を変更せず、ソニフィケーション層と詩的造形層へ明確な
時間構成、局所的因果、躍動感を追加する。現行の「同じ鐘の対を疎に反復し、
全造形を同じ輝度包絡で点滅させる」構成は置き換える。

## 1. 設計目標

1. 固有値、固有関数、係数、位相、境界条件、絶対数学時刻を維持する
2. ガラス鐘と木質アタックをChapter 2の音響アイデンティティとして維持する
3. 75秒の中に認識可能な5幕を作り、密度、奏法、音域、明暗、空間、運動を変化させる
4. 発音したモードと動いた柱・アーチ・粒子帯の対応を説明可能にする
5. Chapter 1の色彩と没入感を継承しつつ、Chapter 2固有の奥行きと定在波を主役にする
6. 同じ品質条件を将来章へ適用できる型、登録時検証、文書上の制約を追加する

## 2. 変更しない数学層

次の値と規約は変更しない。

- 長方形領域、Dirichlet境界条件、12個の解析的固有モード
- 固有値`lambda_mn = m^2 + 2n^2`
- 熱核由来の係数`a_mn`とその符号
- 波動場`u_C(x,y,t)`と絶対transport時刻
- 波動速度`c_C = 0.22 / sqrt(3)`
- 固定格子の厳密標本値、境界、節線、符号色
- 解析表示の固有値軸、符号付き係数、相対エネルギー指標
- 音響で保持する固有振動数比`sqrt(lambda_mn / 3)`
- 音響で保持する係数絶対値比と符号の開始位相`0`または`pi`

厳密波面へ演出用ノイズ、個別位相ずらし、幕ごとの時間伸縮、カメラ依存変形を
加えない。音楽スコアが75秒で反復しても、数学時刻はリセットしない。

## 3. 75秒の舞台構成

テンポは72 BPM、拍子は5/4を維持する。1小節は`25/6`秒とし、18小節、
75秒を1周期とする。

| 幕 | 小節 | 時間 | 役割 | 音響密度 | 視覚運動 |
| --- | ---: | ---: | --- | --- | --- |
| I 点灯 | 0-2 | 0-12.5秒 | 空間と固有モードを一つずつ提示 | 低 | 局所柱の立ち上がり |
| II 回廊 | 3-6 | 12.5-29.167秒 | 左右と奥行きの応答を作る | 中 | アーチ上の伝播 |
| III 上昇 | 7-10 | 29.167-45.833秒 | 密度と音域を段階的に増やす | 中高 | 柱高と粒子速度の上昇 |
| IV 共鳴 | 11-14 | 45.833-62.5秒 | 全体の頂点を作る | 高 | 局所励起の連鎖と最大視差 |
| V 余韻 | 15-17 | 62.5-75秒 | 音数を減らし次周期へ戻す | 低 | 残光を残して収束 |

各幕の境界では、ゲイン、明るさ、残響、ステレオ幅、カメラ位置を最低1小節で
連続補間する。周期境界の位置、速度、色、音量に不連続を作らない。

## 4. 音楽スコア

### 4.1 時間格子

1拍を2分割した8分音符格子、1小節10スロットを基礎とする。全スロットを鳴らさず、
幕ごとに決定的なリズム型を使う。

- 点灯: 1小節あたり2-3イベント
- 回廊: 1小節あたり4-5イベント
- 上昇: 1小節あたり6-7イベント
- 共鳴: 1小節あたり8-9イベント
- 余韻: 1小節あたり2-4イベント

周期全体は90イベント以上120イベント以下とする。平均密度だけでなく、最密幕の
イベント率を最疎幕の2.5倍以上にする。

### 4.2 ジェスチャー

イベントは次のいずれかのジェスチャーを持つ。

- `toll`: 長い単音または2音の鐘。空間提示と余韻に使う
- `answer`: 左右または前後で応答する短い2音
- `cascade`: 固有値順または係数エネルギー順の高速分散
- `pulse`: 木質アタックを強めた短い反復
- `choir`: 3-4モードを同時に鳴らす共鳴頂点

同じジェスチャーを5イベント以上連続させない。同じモード組を同じ発音位置で
2小節連続して反復しない。固定seedのランダム生成ではなく、正準の決定的スコアを使う。

### 4.3 数学量から演奏表現への写像

基礎周波数は引き続き次式を使う。

```math
f_{mn}=176\sqrt{\lambda_{mn}/3}\ \mathrm{Hz}
```

同じイベント内の全モードへ共通のレジスター倍率`1/2`、`1`、`2`のいずれかを
適用してよい。モードごとに異なる倍率を適用して固有振動数比を崩してはならない。

係数絶対値比はイベント内と周期全体で同じ正規化基準を使う。イベント単位の
再正規化は禁止する。符号は開始位相`0`または`pi`へ写す。

絶対イベント時刻`t_e`で各モードの変位成分と速度成分を評価する。

```math
d_{mn}(t_e)=|\cos(c_C\sqrt{\lambda_{mn}}t_e)|
```

```math
v_{mn}(t_e)=|\sin(c_C\sqrt{\lambda_{mn}}t_e)|
```

- `d_mn`は鐘身の持続、暖かさ、残響量へ使う
- `v_mn`は木質アタック、明るさ、短いアクセントへ使う
- 基礎周波数、係数比、符号位相はこれらで変更しない
- 値はイベント表へ保存せず、絶対イベント時刻から評価する

### 4.4 DSP

単一の固定包絡を廃止し、ジェスチャー別の包絡を持つ。

| ジェスチャー | 発音長 | アタック | 主減衰 | 特徴 |
| --- | ---: | ---: | ---: | --- |
| toll | 2.2秒 | 3 ms | 420 ms | 長い鐘身、広い残響 |
| answer | 1.1秒 | 2.5 ms | 240 ms | 明瞭な定位 |
| cascade | 0.62秒 | 2 ms | 125 ms | 高い明瞭度、短い尾 |
| pulse | 0.42秒 | 1.5 ms | 85 ms | 木質成分を強調 |
| choir | 2.6秒 | 5 ms | 520 ms | 低い乾音と広い残響 |

各イベントはゲイン、brightness、wetSend、stereoSpread、registerMultiplierを持つ。
これらは幕プロファイルと絶対時刻由来の`d_mn`、`v_mn`から評価し、有限範囲へ制限する。
既存のEQ、コンプレッサー、リミッターを維持し、出力は-1 dBFS以下とする。
左右デチューン後の全実生成部分音に`0.45 F_s`の帯域条件を適用する。

## 5. 視覚演出

### 5.1 局所モード応答

全造形へ同じ4つのスカラーを渡す現行方式を廃止する。7本の正準アンカー位置
`(x_i,y_i)`と各モードの解析的固有関数から、局所影響行列を初期化時に作る。

```math
M_{i,mn}=\frac{|a_{mn}\phi_{mn}(x_i,y_i)|}
{\max_j |a_{mn}\phi_{mn}(x_j,y_j)|}
```

発音イベントのモード集合だけを使い、柱ごとの励起`p_i(t)`を計算する。
影響行列は詩的造形の選択にだけ使用し、厳密波面の頂点、節線、係数を変更しない。

視覚フレームは次を返す純粋関数として実装する。

- 現在幕、幕進行度、周期進行度
- 7本の柱ごとのimpact、afterglow、height、warmth
- 6本のアーチごとの進行波位置、強度、残光
- 粒子帯ごとのenergy、swirl、verticalSpeed
- カメラのdolly、orbit、targetOffset

すべての値を有限範囲へ制限し、周期境界で連続にする。

### 5.2 光柱とアーチ

- 発音モードの影響が大きい柱を先に伸長・増光する
- 柱高は詩的造形の線分だけを変え、数学面の高さを変更しない
- 隣接柱へ80-220 msの遅延でエネルギーを渡す
- アーチ上に1つまたは2つの光点を移動させ、全アーチ一斉点滅を避ける
- 共鳴幕でも全柱の最大値を同時に固定せず、20-90 msの時間差を残す

### 5.3 粒子

各粒子を初期化時に最寄りアンカーへ割り当てる。粒子更新は割当先柱の局所energyを
使い、上昇速度、螺旋半径、不透明度を変える。全粒子へ同じdustEnergyを適用しない。
粒子の基礎位置とseed決定性は維持する。

### 5.4 カメラ

固定カメラを廃止し、幕構成に同期した緩やかなdollyとorbitを加える。

- 水平orbitは基準構図から最大4度
- dollyは基準距離の最大6%
- 注視点移動は数学面短辺の最大4%
- rollは使用しない
- 速度と加速度を連続にし、発音ごとのカメラ振動は加えない
- リサイズ時のfit計算を基準とし、その後に小さい相対変位を適用する

カメラは空間の躍動を作るが、厳密波面の形状や投影規約の説明を変更しない。

## 6. 将来章を拘束する演出契約

`PatternDefinition`へ章固有の`dramaturgy`メタデータを追加する。

```ts
interface PatternDramaturgySection {
  id: string;
  startRatio: number;
  endRatio: number;
  audioEnergy: number;
  visualEnergy: number;
  motionEnergy: number;
}

interface PatternDramaturgy {
  cycleSeconds: number;
  sections: readonly PatternDramaturgySection[];
  expressiveAxes: readonly (
    | "density"
    | "dynamics"
    | "register"
    | "timbre"
    | "space"
    | "motion"
    | "color"
  )[];
  localMathMapping: boolean;
}
```

`validatePatternDefinition()`は公開章に対して次を拒否する。

- 3幕未満
- 幕範囲が0から1を連続して覆わない
- 3軸未満の表現変化
- audio、visual、motionの全energy差が0.25未満
- `localMathMapping`がfalse
- cycleSecondsが有限正数でない

メタデータだけを満たして実装が単調な状態を防ぐため、各章はスコアまたは応答関数の
単体テストでも幕間コントラストを検証する。`AGENTS.md`へ次を必須条件として追加する。

- 数学的正確性は演出より常に優先する
- 数学を維持できる範囲では単調さの排除と躍動感を最優先する
- 30秒を超える章は3つ以上の認識可能な時間状態を持つ
- 音響・映像・空間の複数軸でコントラストを持つ
- 数学要素と局所演出の因果を説明可能にする
- 自動テストだけで公開せず、実機試聴と連続観察を完了条件にする

Chapter 1は既存の5区間スコアを`dramaturgy`へ記述し、挙動を変更しない。

## 8. テスト

### 音響

- 18小節、75秒、5幕、90-120イベント
- 幕ごとのイベント密度と2.5倍以上のコントラスト
- 同一ジェスチャーと同一モード組の過剰反復がない
- 全12モードが周期内で複数回発音する
- 共通レジスター倍率後もイベント内の固有振動数比を維持する
- 係数比と符号位相を維持する
- 絶対イベント時刻から`d_mn`と`v_mn`を再評価する
- 5ジェスチャーの包絡が開始・終了で連続し、指定時間後に厳密に0となる
- サンプルレート別、左右デチューン後の帯域制限
- WorkletとTypeScript参照レンダーの一致
- 出力ピーク-1 dBFS以下、DCと過大低域がない

### 視覚

- モードごとの7柱影響行列が決定的、有限、0以上1以下
- 異なるモードが異なる主要柱集合を励起する
- 非対象柱へ一律最大値を与えない
- アーチ伝播に時間差がある
- 幕間でvisualEnergyとmotionEnergyに指定差がある
- 柱高、粒子速度、カメラ変位が範囲内
- 75秒周期の直前直後で連続
- 厳密数学面、境界、節線の評価値が詩的応答で変化しない

### アプリケーション

- Chapter 1とChapter 2が`PatternDramaturgy`検証を通る
- 3幕未満、非連続範囲、表現軸不足、コントラスト不足を拒否する
- 章切替、pause、resume、hidden復帰で幕と数学時刻が正しく継続する
- WebGPUと強制WebGL2で同じ数学値と局所応答を使う
