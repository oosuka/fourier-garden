## 十の数学的風景

全10章を通常の章目録へ登録している。各章は5幕の反復スコアを持つ。
以下の秒数は音楽形式の周期であり、数学的な状態や軌道が同じ値へ戻る周期ではない。

| 章 | 数学と主役の形 | 音楽形式 | 音と素材の方向 |
| --- | --- | --- | --- |
| 01 Residue Bloom / 剰余の花 | n=4k+1、13項の有限Fourier級数。円鎖の虚部が履歴波形へ続く | 144秒、80 BPM、4/4、768発音 | 金属糸と薄い絹。270〜340 msの尾が重なり、高次調波の接触が先に薄れる |
| 02 Spectral Cathedral / スペクトルの聖堂 | 長方形の12 Dirichlet固有モード。波面、合成場の節線、固定観測点の柱 | 75秒、72 BPM、5/4、360発音 | 緑と琥珀の石英。第2部分音の短い接触とgesture別の有限尾 |
| 03 Prime Constellation / 素数星座 | 97以下の25素数の有限指数和。25位相点と昇順の24リンク | 60秒、10秒の素数間隔句 | 琥珀の疎な位相空間。素数間隔を保つ点状の発音と現在位相の左右移動 |
| 04 Möbius Choir / メビウスの合唱 | flat Möbius quotientの6固有モード。反転してつながる単一の帯 | 約56.470588秒、68 BPM、256発音 | 真珠色と青灰色の帯。2〜3部分音の母音変化と330〜490 msの尾 |
| 05 Bessel Tide / ベッセルの潮 | 単位円板の17実固有モード。円板と、選択した単独モードの節円・節径 | 72秒、6/8の往復句 | 青磁と水盤。係数の知覚圧縮を施した滴と局所波紋 |
| 06 Lissajous Orchard / リサージュの果樹園 | 9既約比の有理トーラス流の平面射影。主曲線と奥行きの8曲線 | 60秒、9組の32イベント句 | 金緑の弦。曲線をたどる接触と、絶対位相に従う定位 |
| 07 Dirichlet Lanterns / ディリクレの灯 | 4次数のDirichlet核、矩形波の有限部分和とFejér平均 | 60秒、主峰と側葉の応答句 | 琥珀の灯芯、象牙色と赤銅の残火。奇数調波の短いパケット |
| 08 Wavelet Rain / ウェーブレットの雨 | Haarの63ウェーブレット係数とscaling係数。固定支持と64区間の射影 | 64秒、二進クラスタ | 墨と銀の雨。支持から落ちる係数滴と、重なる下降chirp |
| 09 Riemann Veil / リーマンの帳 | 平方数支持の有限和、12／24／48／96項の4層 | 80秒、二次主時刻と2つの応答 | 銅の薄い帳。密集区間を音量補正した下行応答と局所の余韻 |
| 10 Phase Torus / 位相トーラス | T²上の無理比流と、共役対称な24 Fourier文字の有限場 | 84秒、20 slot・4秒の非一様軌道句 | 緑の金属と淡い金。位相変調、回転定位、重なりのある丸い尾 |

素材名はart directionを表す。音響波形が物理的な石英、水、金属の振動を解いたものではない。
色と空間は[視覚設計](visual-design.md)、可聴量への変換は[音響設計](audio-design.md)と
[因果対応表](sound-shape-causality.md)で具体化する。

## 観察から実験へ

各章の「観察ノート」は、感覚的な問い、操作できる比較図、数学の詳細、音への写し方、関連章の順に掘り下げられる。
小さな比較図の操作は本編の音や数学を変更しない。固定した軸と係数のもとで一つの量を変える。

| 章 | 比較図で変える量 | 見つけられる関係 |
| --- | --- | --- |
| Residue | 先頭1〜13項 | 同じ剰余類の調波を足すと、どこに細部が生まれるか |
| Cathedral | 12固有モードの選択 | 領域の辺と整数組が単独モードの節線を決める |
| Prime | 先頭1〜25素数 | 係数1/25を保って、支持集合だけを広げたときの位相和 |
| Möbius | cutoff内の整数組 | m+nの奇偶が継ぎ目での一致・不一致を分ける |
| Bessel | 17実モードの選択 | 径方向の零点と角度方向の零点を分けて観察する |
| Lissajous | 2:3曲線の相対位相 | 整数比と閉曲線を保ったまま形が変わる |
| Dirichlet | 奇数最高次数1〜63 | 同じ次数の部分和と平均で、跳びの近くがどう違うか |
| Haar | 射影レベルJ=0〜6 | 2ᴶ個の区間平均へ情報が局在する |
| Riemann | 12／24／48／96項 | 原点近くを同じ倍率で拡大し、有限和の細部を比べる |
| Torus | 1、3/2、7/5、√2の速度比 | 反対辺を同一視した有限軌跡の戻り方を比べる |

実験の定義と表示上の限界は[数学探索](mathematical-exploration.md)を参照する。

## 章をまたぐ問い

- Residue → Prime → Riemann：整数の支持を剰余類、素数、平方数へ変えると、位相の重なりはどう変わるか。
- Cathedral → Möbius → Bessel：領域と境界・同一視が変わると、許される固有モードと節はどう変わるか。
- Dirichlet → Haar：大域的な三角関数と局在した基底は、同じ「近似」をどのように見せるか。
- Lissajous → Torus：有理比の閉じた流れから、無理比の流れへ移ると何が変わるか。

関連章ボタンと章遷移の一文は、この比較を鑑賞の中で発見する入口にする。
前章の短い描画残像と音の減衰を共通の時計へ結び付け、次章の最初の音と光を新しい共通epochから始める。

## 共通条件と完成判定

[registryの検証](../src/patterns/registry.ts)は、隣接章の7表現軸のうち5軸以上、
音響5軸のうち3軸以上で識別子が異なることを確認する。これは設計の取り違えを防ぐ条件であり、
実際に見聞きした個性や5幕の対比を証明するものではない。

数学時刻は絶対transport時刻とし、厳密な座標・係数へ装飾ノイズを足さない。
音はソニフィケーションとして、保持する量と知覚上変換する量を章ごとに明示する。
全周期dry stereo RMSの基準は0.023 ±0.05 dB。デチューン、chirp、位相変調を含む
実生成carrierを0.45 Fs未満へ制限する。有限包絡の信号全体が厳密な帯域有限であるとは主張しない。

WebGPU／WebGL2、16:10／16:9／21:9、高DPI、4K、長時間同期、章切替と資源破棄、
音なし鑑賞とreduced motionを現行ビルドで確認する。負荷時は装飾を先に減らす。
音だけ、映像だけ、同時体験を別々に評価し、数値指標や静止画を感覚的品質の代用にしない。
未観測の物理出音・画面走査遅延は未測定として記録する。

現状品質版はユーザー受入済み。全10章の客観的な未測定項目は[実装計画](superpowers/plans/2026-09-06-renewal.md)と
[作業記録](qa/renewal/progress.md)に集約し、将来の章の追加をV2の完了条件に含めない。
