# Fourier Garden 数理モデル

## 文書の位置付け

この文書は2026年7月5日時点の正式版で通常公開済みのChapter 1
`Residue Bloom`、Chapter 2 `Spectral Cathedral`、Chapter 3
`Möbius Choir`の数学、時間、解析表示、ソニフィケーション規約の正本である。
Chapter 4以降のAtlas案は、個別数理仕様の承認と実装が完了するまで本書へ追加しない。

## プロダクトの定義

Fourier Gardenは、有限フーリエ級数の合成、複素指数関数・フェーザによる
フーリエ級数の可視化、そのコンセプトから導かれる映像と音声を奏でる
オーディオビジュアル作品である。

本作品はFFT（高速フーリエ変換）アルゴリズムの可視化ではない。
`Residue Bloom`の係数は最初から解析的に与えられており、標本列にDFTや
FFTを適用して係数を推定していない。

## Chapter 1: Residue Bloom（通常公開）

### 有限フーリエ級数

最初の章は

\[
f(x)=5\sum_{k=0}^{12}\frac{1}{k+1}\sin((4k+1)x)
\]

を扱う。以下の記号を用いる。

\[
n_k=4k+1,\qquad A_k=\frac{5}{k+1},\qquad \phi_k^{(\sin)}=0.
\]

したがって、採用する調波番号は

\[
1,5,9,\ldots,49
\]

であり、すべて

\[
n_k\equiv1\pmod4
\]

を満たす。

### フェーザ表現

一方向に回転する複素フェーザの和を

\[
z(x)=\sum_{k=0}^{12}A_k e^{i(n_kx+\phi_k^{(\sin)})}
\]

と定義する。この章では位相がすべて0なので、

\[
f(x)=\operatorname{Im}z(x)
\]

である。

各円の半径は\(A_k\)、角速度は\(n_k\)、円を順番につないだ終点は
\(z(x)\)である。画面右側の主履歴波形は、この終点の虚部を同じ倍率で
時間方向へ並べたものである。描画は解析式から評価した厳密な標本点を
線分で結ぶ数値描画であり、各標本座標は有限級数そのものの幾何学的射影と
一致する。有限個の線分を連続曲線そのものとはみなさない。

表示時間については、構造を目で追えるよう

\[
x(t)=0.31t
\]

とする。これは観察用の時間伸長である。55 Hzという表記は後述する
解析的スペクトルの周波数対応であり、画面上の基本フェーザが実時間で
55回転毎秒することを意味しない。

数学表示の\(t\)は絶対トランスポート時刻であり、後述する144秒の音楽形式で
リセットしない。

### 複素フーリエ係数

実関数の標準的な二側複素フーリエ級数

\[
f(x)=\sum_{n=-\infty}^{\infty}c_ne^{inx}
\]

で表す場合、この章の非零係数は

\[
c_{n_k}=-\frac{iA_k}{2},
\qquad
c_{-n_k}=\frac{iA_k}{2}.
\]

正負の係数が複素共役になるため、合成結果は実数である。

画面の係数表に表示する\(A_k\)は正弦形式の振幅であり、複素係数の絶対値
\(|c_{\pm n_k}|=A_k/2\)とは区別する。

### 解析的スペクトル

表示するスペクトルはFFT推定値ではない。基準周波数を
\(f_0=55\ \mathrm{Hz}\)としたとき、既知の各項を

\[
f_k=n_kf_0
\]

へ配置した解析的係数スペクトルである。片側表示の棒高は正弦形式の振幅
\(A_k\)であり、\(|c_{\pm n_k}|=A_k/2\)ではない。棒と目盛は同じ対数座標関数を
使用する。

### 音楽的ソニフィケーション

音声は\(f_0=55\ \mathrm{Hz}\)の級数を無加工で再生したものではない。
80 BPM、4/4、1拍4ステップ、1小節16ステップとし、48小節を144秒で循環する
決定的なイベントスコアを用いる。区間は次のとおりである。

| 区間 | 小節 | 時間 |
| --- | ---: | ---: |
| 導入 `intro` | 0-7 | 0-24秒 |
| 成長 `growth` | 8-19 | 24-60秒 |
| 開花 `bloom` | 20-31 | 60-96秒 |
| 静寂 `hush` | 32-39 | 96-120秒 |
| 再開 `return` | 40-47 | 120-144秒 |

小節内の0始まり16分音符位置を用い、全区間で発音マスク

\[
S=\{0,1,\ldots,15\}
\]

を使う。約0.1875秒間隔の一定パルスを保ち、`intro`、`growth`、`bloom`、
`hush`、`return`の差は基礎ゲイン、明度、ウェット送出、ステレオ幅、
詩的造形強度で作る。最後の小節では音響・詩的造形のプロファイルを
導入冒頭へ戻す。全16分を埋める一定時計は保ちながら、sectionごとの4発音アクセント、
小節ごとのローテーション、16ステップのゴースト輪郭で、Chapter 1固有の花弁状の重心移動を
聴感上のリズム差として与える。

| section | 4発音アクセント |
| --- | --- |
| `intro` | `[1.00, 0.64, 0.90, 0.72]` |
| `growth` | `[0.90, 0.74, 1.08, 0.66]` |
| `bloom` | `[1.10, 0.70, 0.94, 0.82]` |
| `hush` | `[0.72, 0.58, 0.84, 0.62]` |
| `return` | `[0.92, 0.66, 1.00, 0.78]` |

section内の小節番号を\(b_s\)とすると、発音ordinal由来の4音indexを
\((j+b_s)\bmod4\)で参照する。各小節のdownbeatだけ1.08倍する。
さらに16ステップのゴースト輪郭

\[
H=[1.14,0.48,0.82,0.52,1.00,0.46,0.78,0.50,1.06,0.48,0.80,0.54,0.96,0.46,0.74,0.50]
\]

を使い、発音slot \(s\)では\(H_{(s+3b_s)\bmod16}\)を乗じる。
評価済みアクセントは\([0.30,1.36]\)へ制限する。これは全16分slotを鳴らしたまま、
弱いゴースト粒と移動する強拍アンカーを作るための音楽的写像である。
評価済みアクセントを\(a_e\)、区間由来の基礎brightnessを\(B_s\)とすると、
イベントの基礎brightnessは

\[
B_e=\operatorname{clamp}(B_s+(a_e-0.70)\cdot0.26,0,1)
\]

で決める。さらに、後述する有限エンベロープの減衰倍率を

\[
D_e=(0.88+0.24p_r)\operatorname{clamp}(0.16+1.08a_e,0.52,1.55)
\]

とする。これにより、強拍は明るく長く、弱拍は暗く短く聴こえる。
これらはソニフィケーション層の音色と包絡の写像であり、係数、キャリア列、
数学時刻、厳密フェーザ座標は変更しない。

音楽形式の周期時刻を

\[
t_{\mathrm{cycle}}=t\bmod144
\]

とする。一方、周回番号を\(m\)、反復表内のイベント時刻を
\(t_e^{\mathrm{local}}\)とすると、実際に発音した絶対イベント時刻は

\[
t_e^{\mathrm{abs}}=m\cdot144+t_e^{\mathrm{local}}
\]

であり、フェーザ制御は

\[
z_e=z(0.31t_e^{\mathrm{abs}})
\]

から毎周回評価する。144秒で反復するのは音楽形式であり、数学位相ではない。

各有効発音について、キャリアを

\[
\nu_j\in\{9f_0,8f_0,8f_0,9f_0\}
=\{495,440,440,495\}\ \mathrm{Hz}
\]

とし、生の16分音符番号ではなく有効発音の通算順序で循環させる。

基礎知覚重みと左右実周波数を

\[
w_k=\frac{A_k}{(k+1)^{1.85}},
\qquad
f_{k,j}^{L/R}=n_k\nu_j(1\mp d),
\qquad d=0.00125
\]

とする。等電力定位係数を\(P_k^{L/R}\)、基礎ゲインと評価済みアクセントの積を
イベントゲイン\(G_e\)、12 ms attack、110 ms decay、55 ms releaseを持つ
有限エンベロープを\(E_e(\tau)\)、正規化係数を\(C\)
とすると、ローパス前の左右信号は

\[
g_{\nu_j}^{L/R}(\tau)=
CG_eE_e(\tau)
\sum_{k\in K(F_s)}
w_kP_k^{L/R}
\sin(2\pi f_{k,j}^{L/R}\tau)
\]

である。採用集合\(K(F_s)\)は

\[
\max\left(
n_k\nu_j(1-d),
n_k\nu_j(1+d)
\right)<0.45F_s
\]

を満たす項である。この条件はナイキスト周波数\(F_s/2\)に対して余裕を設け、
名目周波数ではなく左右デチューン後の最大実周波数へ適用する。48 kHz時には
440 Hzキャリアで13項、495 Hzキャリアで11項が採用される。

#### イベント時フェーザの有界写像

絶対イベント時刻\(t_e^{\mathrm{abs}}\)で、表示と同じ角速度を使って

\[
z_e=z(0.31t_e^{\mathrm{abs}}),\qquad M=\sum_{k=0}^{12}A_k
\]

を評価する。正規化値を

\[
p_x=\operatorname{clamp}\left(\frac{\operatorname{Re}z_e}{M},-1,1\right),
\]

\[
p_y=\operatorname{clamp}\left(\frac{\operatorname{Im}z_e}{M},-1,1\right),
\qquad
p_r=\operatorname{clamp}\left(\frac{|z_e|}{M},0,1\right)
\]

とする。\(p_x\)はイベント中心の定位、\(p_y\)は後段ローパスの明るさ、
\(p_r\)はアクセントと減衰へ有界に写像する。

基礎知覚重み

\[
\frac{A_k}{(k+1)^{1.85}}
\]

は変更しない。動的な明るさは部分音合成後の1極ローパスであり、
カットオフは520 Hzから\(\min(2050,0.20F_s)\) Hzの範囲へ写す。
係数\(A_k\)や基礎知覚重みの変更ではない。動的な空間量は生成済みconvolverへ
送る区間プロファイル由来のウェット送出であり、\(p_r\)からは得ない。
さらにステレオデチューン、EQ、コンプレッションを適用する。Chapter 1の
Web Audioグラフはdry high-pass 190 Hz、high-shelf 1,250 Hz / -16 dB、
dry low-pass 2,100 Hz、wet high-pass 220 Hz、wet low-pass 1,450 Hz、
1.15秒残響、threshold -14 dBの圧縮、-1 dBFS limiterを使う。
これらは数学層の同一表示ではなく、調波構造を聴覚へ写すための音響演出である。

反復イベント表はTypeScriptで一度だけ生成し、描画とAudioWorkletへ同じ
プレーンデータを渡す。表は区間、発音、キャリア、基礎プロファイルだけを保持し、
フェーザ座標、半径、フェーザ由来の明るさ・アクセントを保持しない。
AudioWorkletは区間、発音マスク、キャリア順序、フェーザ写像を独自定義せず、
渡されたイベント表と直列化可能なフェーザ写像をサンプル精度で評価する。

### 詩的な造形層

粒子、光の膜、星雲、ブルーム、二次トレイルは、音声と同じ48小節イベント表、
トランスポート、焦点、色彩設計を共有する。イベント時の\(p_x,p_y\)は履歴終点の
バースト起点を再構成するために使うが、現在の円、スポーク、終点、接続線、
主波形の座標は変形しない。これらの装飾をフーリエ級数の値、係数、
DFT、FFTの計算結果として解釈してはならない。

深度別の全画面粒子、手続き生成の星雲、局所発光残光、bloomも詩的造形層である。
絶対transport時刻と局所visual responseを共有するが、厳密な13個の円、スポーク、終点、
接続線、主波形の値または係数解析結果ではない。品質別の全粒子予算は
`14,000 / 32,000 / 64,000 / 96,000`であり、品質変更でも厳密数学層は削減しない。
このうち局所粒子はWebGPUで`4,000 / 8,000 / 12,000 / 16,000`、発音バーストは
4 slot合計768点である。残りを全画面環境粒子へ割り当てる。WebGL2では局所粒子を
`3,000 / 5,000 / 7,000 / 9,000`へ抑え、全画面環境粒子の実描画上限を8,000点にする。
環境層は3深度帯の粒子、5枚の星雲ベール、6本のフィラメントベールを持つ。

#### 調波コロナと節点

発音時の調波コロナは、厳密な13個の円と同じジオメトリ、位置、倍率を持つ
別ラインである。調波ごとの基礎強度は、音響で維持する知覚重みを

\[
q_k=
\frac{A_k/(k+1)^{1.85}}
{\max_{0\le j\le12}\left(A_j/(j+1)^{1.85}\right)}
\]

として正規化した値から得る。\(q_k\)は別ラインの不透明度へだけ写し、
厳密円の半径\(A_k\)、位相\(n_kx\)、位置を変更しない。

14個の光点はスポーク開始点と13個のフェーザ終点の座標をそのまま使う
別の点描画である。イベントにより色、不透明度、点サイズを変えてよいが、
スポークと終点の座標は変形しない。

#### 履歴パルス

直近の有効イベントは最大4件まで保持する。イベントからの経過時間を\(a\)秒とし、
8.6秒分を表示する主履歴波形上の中心位置を

\[
u_e=\operatorname{clamp}\left(\frac{a}{8.6},0,1\right)
\]

とする。履歴パルスの各点は主波形と同じ
`projectSeriesToVerticalAxis()`を使い、

\[
y(u)=s\,f\left(0.31(t-8.6u)\right)+y_0
\]

で計算する。したがってパルスは主波形上の点だけを通る。パルスの短い表示区間、
色、不透明度、光点サイズは詩的造形だが、白い主波形の座標、位相、倍率へ
ノイズ、テーパー、Yオフセットを加えない。二次トレイルだけは詩的な上下移動を
持ってよい。

### 正確性の不変条件

実装では次を自動テストする。

- 13項の調波番号、振幅、正弦位相
- 直接評価した\(f(x)\)とフェーザ終点の虚部の一致
- 二側複素係数の値と共役対称性
- 主波形の投影倍率とフェーザ終点の一致
- 数学時刻が144秒の音楽周期でリセットされないこと
- 反復イベント表に評価済みフェーザ値が入らないこと
- ソニフィケーションの知覚重みと左右デチューン後の帯域制限
- スペクトル棒と目盛が同じ対数座標関数を使うこと
- 章定義の数学的由来、係数、振幅上限、周波数対応基準が一致すること
- 発音間に無音へ近い減衰があり、低い持続音にならないこと
- 調波コロナの13個の正規化重みと単調減少
- 履歴パルスの各点と主波形射影式の一致
- 厳密な主波形に詩的なYオフセットがないこと

## Chapter 2: Spectral Cathedral（通常公開）

Chapter 2は長方形領域

\[
\Omega=(0,\pi)\times(0,\pi/\sqrt2)
\]

のDirichlet Laplacian固有モードを扱う。純粋数学モデル、ソニフィケーション、
厳密数学描画、詩的造形、通常アプリの章切替、詳細パネルを実装している。
通常URLでChapter 1と往復でき、`patternRegistry`へ公開済み章として登録する。
ヘッドホンとMac内蔵スピーカーの最終試聴は、公開状態と分けた手動QA事項として残す。
2026年6月までの詳細設計と実装計画は現行正本へ集約済みのため、本文からは参照しない。
履歴上の位置付けだけを
[`docs/superpowers/README.md`](superpowers/README.md)に残す。
以下の厳密数学定義は再設計でも変更しない。

正規直交固有関数と固有値を

\[
\phi_{mn}(x,y)=\frac{2}{\sqrt{L_xL_y}}
\sin\left(\frac{m\pi x}{L_x}\right)
\sin\left(\frac{n\pi y}{L_y}\right),
\qquad
\lambda_{mn}=m^2+2n^2
\]

とする。有限集合は\(\lambda_{mn}\le30\)の12モードであり、
\(\lambda=27\)の\((3,3)\)と\((5,1)\)を固定した解析的正弦基底として
別々に保持する。

係数を

\[
\widetilde a_{mn}=e^{-0.08\lambda_{mn}}\phi_{mn}(q_0),
\qquad
q_0=(L_x/\sqrt2,L_y/\sqrt3),
\qquad
a_{mn}=
\frac{\widetilde a_{mn}}{\sum_{\mathcal K_C}|\widetilde a_{pq}|}
\]

とし、\(\sum|a_{mn}|=1\)を満たす。波動場は

\[
u_C(x,y,t)=
\sum_{\mathcal K_C}
a_{mn}\cos(c_C\sqrt{\lambda_{mn}}t)\phi_{mn}(x,y),
\qquad
c_C=\frac{0.22}{\sqrt3}
\]

である。数学時刻\(t\)は絶対transport時刻であり、後続する音楽スコアの
周期ではリセットしない。

振幅上限と表示写像を

\[
B_C=\frac{2}{\sqrt{L_xL_y}},
\qquad
U_C=\frac{u_C}{B_C},
\]

\[
X=\frac{2x}{L_x}-1,
\qquad
Y=\frac{2y}{L_x}-\frac{L_y}{L_x},
\qquad
Z=0.60U_C
\]

とする。解析表示は線形固有値軸、符号付き係数\(a_{mn}\)、
相対エネルギー指標\(a_{mn}^2\lambda_{mn}\)を用いる。
この指標を物理的な波動エネルギーやHzスペクトルとは呼ばない。

固有値、固有関数、係数、波動場は解析式から直接評価し、DFT、FFT、
数値固有値問題を使用しない。

### Chapter 2の厳密数学描画

数学面は境界を含む\(192\times128\)固定格子で解析式を評価し、
24,576頂点、48,514三角形の区分線形面として描く。格子座標、三角形
インデックス、12モードの空間基底、曖昧セル用の中心基底は初期化時に生成し、
毎フレーム再生成しない。

WebGPUとWebGL2には、CPUで評価した同じ正規化場、頂点位置、頂点色、
節線座標を渡す。バックエンドごとに波動式や色式を再実装しない。
数学面の色は\(U_C\)の符号と絶対値だけから決め、正値をシアンから白銀、
負値を青紫から白銀へ写す。\(|U_C|\le10^{-10}\)は低輝度の数学的零として
扱う。照明、音楽イベント、品質、seed、rendererを色入力へ使わない。

節線は同じ格子標本からmarching squaresで抽出する。辺交点は隣接標本値の
線形補間で求め、4辺が交差する曖昧セルは解析式から得たセル中心値で接続を決める。
中心値も零なら4交点を中心へ接続し、任意の二方向へ分解しない。外周の
Dirichlet零集合は独立した長方形境界へ一本化し、同じ外周辺上に重なる
節線線分だけを除外する。内部節線が境界へ到達する線分は保持する。

この面は解析式の固定格子標本を三角形で結ぶ数値描画であり、連続解析曲面
そのものではない。節線も同じ標本に基づく補間近似であり、解析的零点集合
そのものとは呼ばない。

解析表示は12モード表、線形固有値軸\([0,30]\)、符号付き係数、
相対エネルギー指標、絶対数学時刻を別々に示す。\(\lambda=27\)の
\((3,3)\)と\((5,1)\)は同じ横軸位置に別IDで保持する。軸はHzまたは
FFTスペクトルではない。

品質レベル`low`、`medium`、`high`、`ultra`は、数学面、境界、節線、
解析表示、文字、頂点数、三角形数を変更しない。

### Chapter 2の詩的造形

光柱アンカーは、時刻0の正規化場\(|U_C(x,y,0)|\)を厳密描画と同じ
`192 x 128`格子で評価し、境界を除く8近傍局所極大から最大8点まで選ぶ。
候補は絶対値の降順、同値なら元領域のX、Y昇順とし、既選択点との距離が
`0.12L_x`未満の候補を除外する。正準定義では局所極大が7点あり、
距離選別後も7点すべてを保持する。局所極大でない8点目を補充しない。

この7座標へ垂直な光柱芯を置き、表示X、Y順に隣接する点を6本のアーチ芯で結ぶ。
光柱の高さ、幅、体積ハロー、アーチ曲率、塵状粒子、短い残光は
詩的な量である。光柱を反節点、固有関数、固有値、係数とは呼ばず、
アーチを節線接続、領域の位相、測地線とは呼ばない。

柱芯の基礎座標とアーチ中心曲線は固定する。各モードと柱の局所影響を

\[
M_{i,mn}=\frac{|a_{mn}\phi_{mn}(x_i,y_i)|}
{\max_j|a_{mn}\phi_{mn}(x_j,y_j)|}
\]

で定義する。発音イベントのモード集合だけを使って7本の柱ごとの励起を計算し、
柱の詩的な高さ、輝度、ハローへ写す。6本のアーチは隣接柱の励起を
80 msから220 ms遅延させ、アーチ上の光点と残光へ写す。全柱と全アーチへ
同じ発音包絡を一律適用しない。

視覚包絡は`gesture`ごとに異なり、`pulse`の0.54秒から`choir`の2.8秒まで
短く閉じる。反復スコアは75秒で循環し、周期境界では前周期の余韻も絶対イベント
時刻から評価する。数学面の頂点位置、頂点色、境界、節線、係数表示は局所影響、
幕、カメラ、seedから変更しない。数学時刻は75秒のスコア周期で折り返さない。

カメラはfit計算で得た基準構図に対して、75秒周期の連続軌道を加える。水平orbitは
最大8度、dollyは基準距離の最大10%、注視点移動は表示座標でX方向0.06、Y方向0.04とし、
rollと発音ごとの振動は使用しない。カメラは観察位置を変えるだけで、数学面の
頂点、値、投影規約を変更しない。

seedが変更してよいのは、粒子の基礎位置、速度、位相、色カテゴリ、
柱の呼吸位相、装飾色の小さい輝度差だけである。seedは7アンカーの座標、
6アーチの中心曲線、数学面、境界、節線、モード、係数、固有値、
数学時刻、スコアイベント時刻へ影響しない。

詩的粒子は最大52,000点の固定容量を初期化時に作り、各粒子を最寄りの正準柱へ
決定的に割り当てる。割当柱の局所energyで上昇速度、螺旋半径、位相速度を変える。
品質変更ではdraw rangeだけを`10,000`、`22,000`、`38,000`、`52,000`へ変える。
品質低下は粒子、体積ハロー、アーチ残光の順に適用する。
正準7本の柱芯、6本のアーチ芯、数学面、境界、節線、解析表示は削減しない。

正準アーチ芯から派生する5本の細いfilament、透明膜、奥行き方向の4反復ヴォールト、
柱shell、領域全体を覆う9本の大ヴォールト肋材は詩的造形である。大ヴォールト肋材は
正準アーチや固有モードから導いた線ではなく、全画面構図の奥行きを作る装飾である。
正準アーチ芯と7アンカーを変更せず、品質低下では派生線、遠景反復、大ヴォールト肋材を
削減する。大ヴォールト肋材の表示本数は`3 / 5 / 7 / 9`とする。全画面環境粒子を加えた総粒子予算は
`16,000 / 44,000 / 86,000 / 128,000`であり、環境粒子は
`6,000 / 22,000 / 48,000 / 76,000`である。環境層は3深度帯の粒子、
5枚の星雲ベール、6本のフィラメントベールを持つ。WebGL2では環境粒子の実描画上限を
8,000点にし、体積ハロー数をhigh以下で先に削減する。

WebGPUとWebGL2は品質別のbloom profileを使い、highではstrength 1.05、
radius 0.42、threshold 0.72を基準にする。柱芯、透明ハロー平面、
アーチ残光、粒子の局所加算合成と組み合わせて発光中心と周辺光を分ける。
WebGL2の粒子は同じ個数と基礎配列を維持しつつ、実ブラウザQAで面と節線を
覆わないようWebGPUより細く低不透明度にする。両backendは同じアンカー、
アーチ中心曲線、seed由来粒子基礎配列を使う。

### Chapter 2の反復スコア

音楽スコアは72 BPM、5/4拍子、18小節であり、1拍は\(5/6\)秒、
1小節は\(25/6\)秒、周期は75秒である。1拍を4分割した16分音符格子を使い、
全小節の20 slotすべてへ発音を置く。5幕は

```text
illumination: 0-2小節
procession:   3-6小節
ascent:       7-10小節
resonance:   11-14小節
afterglow:   15-17小節
```

とする。周期内イベント数は18小節×20 slotの360イベントである。密度で展開せず、
参照動画のような一定リズムを優先し、幕ごとに基礎ゲイン、brightness、wet send、
stereo spread、gesture配列、選択モードを変える。発音gestureは`toll`、
`answer`、`cascade`、`pulse`、`choir`の5種類であるが、音色上はすべて短い
中域ピコ粒へ丸める。4 slotアクセントは`[1.00, 0.70, 0.96, 0.66]`で、
wet sendは最大0.055、stereo spreadは最大0.38に制限し、Chapter 3より乾いた
格子状のキャラクターを保つ。

イベント表は周期内時刻、幕、gesture、モードID、基礎ゲイン、基礎brightness、
wet send、stereo spread、全モード共通register倍率だけを保持する。
絶対イベント時刻、モード変位、モード速度、数学位相、場の値、描画座標は保存しない。
周回\(q\)、周期内イベント時刻\(t_e\)に対して

\[
t_e^{\mathrm{abs}}=75q+t_e
\]

を発音時に評価する。数学時刻はスコア周期でリセットしない。

### Chapter 2のソニフィケーション

各数学モードを短い電子粒へ写す基礎周波数、利得、開始位相を

\[
f_{mn}=420+
\frac{\sqrt{\lambda_{mn}}-\sqrt{\lambda_{\min}}}
{\sqrt{\lambda_{\max}}-\sqrt{\lambda_{\min}}}(980-420)\ \mathrm{Hz},
\qquad
g_{mn}=\frac{|a_{mn}|}{\max|a|},
\]

\[
\varphi_{mn}(t_e^{\mathrm{abs}})
=c_C\sqrt{\lambda_{mn}}\,t_e^{\mathrm{abs}}
+\begin{cases}
0,&a_{mn}\ge0,\\
\pi,&a_{mn}<0
\end{cases}
\]

とする。参照動画に近い一定した中域粒状連続性をQA基準にしたため、発音に使う部分音は
単一の基音\(r=1\)だけであり、イベントは全モード共通のregister倍率\(R=1\)を持つ。
公開DSPは短い包絡、低いwet send、高域抑制を固定し、乾いた幾何学的なピコ粒として扱う。
左右デチューン比を\(d=0.00125\)とし、

\[
\max\left(Rrf_{mn}(1-d),Rrf_{mn}(1+d)\right)<0.45F_s
\]

を満たさない部分音は左右とも除外する。イベントごとには再正規化せず、360イベントで
最大の係数利得和、基礎ゲイン、部分音重み積を全イベント共通の正規化定数として使う。
1音は中央、複数音はイベントの`stereoSpread`内へ等間隔に置き、

\[
P^L=\sqrt{(1-p)/2},
\qquad
P^R=\sqrt{(1+p)/2}
\]

で定位する。

絶対イベント時刻のモード変位とモード速度を

\[
d_{mn}(t_e)=|\cos(c_C\sqrt{\lambda_{mn}}t_e)|,
\qquad
v_{mn}(t_e)=|\sin(c_C\sqrt{\lambda_{mn}}t_e)|
\]

とする。\(d_{mn}\)は減衰時間とwet send、\(v_{mn}\)は部分音brightnessと
丸いアタックへ有界に写す。現在の公開DSPでは単一部分音のため、brightnessは
高次部分音を増やさず、包絡とwet sendの微小変化としてだけ働く。基礎周波数、
係数比、符号位相は変更しない。

ピコ粒の包絡とsubgrainはgestureごとに異なる。subgrainはcarrierを再始動せず、
絶対時刻carrierへ掛ける有限包絡である。

| gesture | attack | 主減衰 | fade開始 | 終了 | subgrain gain |
| --- | ---: | ---: | ---: | ---: | ---: |
| toll | 8 ms | 48 ms | 122 ms | 150 ms | 0.86 |
| answer | 8 ms | 50 ms | 122 ms | 150 ms | 0.92 |
| cascade | 6 ms | 46 ms | 116 ms | 145 ms | 1.00 |
| pulse | 6 ms | 44 ms | 112 ms | 140 ms | 1.00 |
| choir | 9 ms | 52 ms | 126 ms | 155 ms | 0.80 |

各包絡は終了28-34 ms前から余弦fadeし、終了時刻以後は厳密に0を返す。
集団的な連続性は、短い粒を16分格子で常時重ね、低いwet sendで隙間を埋めて作る。
Chapter 2は乾いた幾何学的な輪郭を持つため、Chapter 3より短い包絡、
低いwet send、狭い定位幅を使う。

Chapter 2のWeb Audioグラフはdry high-pass 220 Hz、high-shelf 1,200 Hz /
-18 dB、dry low-pass 1,300 Hz、wet high-pass 220 Hz、wet low-pass 1,050 Hz、
0.55秒の残響、
threshold -16 dBのコンプレッサーを使う。コンプレッサー後には
4倍oversamplingのhard-clampを置き、出力を原則として\(-1\) dBFS以下へ保護する。
この音声は波動場の無加工再生ではなく、固有値、係数比、符号位相、
絶対数学時刻を保った音楽的ソニフィケーションである。

## Chapter 3: Möbius Choir（通常公開）

Chapter 3はflat quotient

\[
M_1=(0,\pi)\times[0,\pi]/((x,0)\sim(\pi-x,\pi))
\]

を扱い、商を取る前の計量を\(dx^2+dy^2\)、境界\(x=0,\pi\)をDirichlet条件とする。
\(y=0,\pi\)は境界ではなく、横断方向を反転して同一視する切断辺である。

複素モード\(\sin(mx)e^{iny}\)は

\[
\sin(m(\pi-x))e^{in\pi}=(-1)^{m+n+1}\sin(mx)
\]

を満たすため、商空間上の関数へ降りる必要十分条件は\(m+n\)が奇数である。
有限モード集合は

\[
\mathcal K_M=\{(m,n)\in\mathbb N\times\mathbb N_0\mid
m+n\text{は奇数},\ m^2+n^2\le13\}
\]

で、正準順序は

\[
(1,0),(1,2),(2,1),(3,0),(2,3),(3,2)
\]

とする。固有値は\(\lambda_{mn}=m^2+n^2\)、係数は

\[
b_{mn}=\frac{C_M}{1+\lambda_{mn}},\qquad C_M=\frac{105}{113},
\qquad\sum b_{mn}=1
\]

である。時間発展は

\[
u_M(x,y,t)=\sum_{(m,n)\in\mathcal K_M}b_{mn}\sin(mx)
\cos\left(ny-\sqrt{\lambda_{mn}}\,0.14t\right)
\]

とする。数学時刻\(t\)は絶対transport時刻であり、56.470588秒の音楽周期で
リセットしない。各モードは\(u_{tt}=0.14^2\Delta u\)を満たし、\(n>0\)の
位相線は正の\(y\)方向へ進む。\(n=0\)は単一余弦位相、\(n>0\)は余弦・正弦の
quadrature pairとして扱う。DFT、FFT、数値Laplace–Beltrami固有値解析は使用しない。

### Chapter 3の表示写像と厳密描画

\(w=x-\pi/2\)、\(R=2.4\)として

\[
F(x,y)=\left(w\cos y,(R+w\sin y)\cos2y,(R+w\sin y)\sin2y\right)
\]

へ写す。これはflat quotientの同一視と節線を観察する非等長埋め込みであり、
埋め込み曲面の誘導計量に対する固有モードではない。曲面へ固定した表側・裏側も
定義しない。

厳密面は\(y\)方向256、\(x\)方向48の12,288頂点、24,064三角形で標本化し、
最終\(y\)列から先頭列へのindexを横断方向に反転する。同じCPU評価済み\(u_M\)を
WebGPUとWebGL2のvertex colorへ渡し、ゼロ等高線を解析的なcell center判定を伴う
piecewise-linear contourとして抽出する。Dirichlet境界は一つの閉じた境界成分、
同一視辺は境界と区別した継ぎ目として表示する。有限三角形や線分を連続曲面・節線
そのものとは説明しない。品質低下では厳密面、境界、継ぎ目、節線、解析文字を削減しない。

### Chapter 3の反復スコアとソニフィケーション

テンポは4分音符68 BPM、1小節は4拍を16分音符16 slotへ分ける。
16小節の周期は\(960/17=56.470588\ldots\)秒で、全小節の16 slotすべてへ
発音を置き、合計256イベントを5幕へ置く。密度は一定に保ち、幕ごとに基礎ゲイン、
wet send、定位幅、連続制御depth、gesture配列、選択モードを変える。
4 slotアクセントは`[0.78, 1.00, 0.68, 0.92]`で、Chapter 2の乾いた格子ではなく、
2拍目に重心が来る流動的な帯として聴こえるようにする。pan motionは最小0.32、
最大0.72以上を不変条件にし、左右運動でChapter 2から分離する。

| 幕 | 小節 | slot | イベント数 | 部分音 | 主gesture |
| --- | ---: | --- | ---: | ---: | --- |
| breath | 0–2 | `0..15` | 48 | 1 | call / answer / breath |
| antiphon | 3–5 | `0..15` | 48 | 1 | call / answer / turn |
| inversion | 6–9 | `0..15` | 64 | 1 | turn / call / answer |
| interweave | 10–13 | `0..15` | 64 | 1 | braid / turn / answer |
| confluence | 14–15 | `0..15` | 32 | 1 | converge / answer / call |

前周期の余韻は絶対イベント時刻で評価する。基礎周波数と係数利得は

\[
f_{mn}=420+
\frac{\sqrt{\lambda_{mn}}-\sqrt{\lambda_{\min}}}
{\sqrt{\lambda_{\max}}-\sqrt{\lambda_{\min}}}(920-420)\ \mathrm{Hz},
\qquad
g_{mn}=\frac{b_{mn}}{b_{10}}=\frac{2}{1+\lambda_{mn}}
\]

である。\(n=0\)は単独声部、\(n>0\)は0と\(-\pi/2\)の位相差を持つ二声部にする。
DSPで採用するcarrierはevent ageで再始動せず、絶対時刻\(t\)で

\[
\cos\left(2\pi f_{mn,r}^{L/R}t+r(0.14\sqrt{\lambda_{mn}}t+q\pi/2)\right),
\qquad q\in\{0,-1\}
\]

と評価する。観察lane \(y_i=(i-1)\pi/6\)の位相
\(\phi_i(t)=n_iy_i-0.14\sqrt{\lambda_i}t\)から、\(|\cos\phi_i|\)を振幅、
\(\sin\phi_i\)を定位へ連続写像する。高域付加明度、フォルマント系付加音、
ノイズ状付加音源は公開DSPでは0にし、単一部分音の短い電子粒、定位、EQ、圧縮、
低い残響だけを加える。
`call`、`answer`、`turn`、`braid`、`converge`などのgestureはcarrierを
再始動しない短い包絡差であり、数学時刻とモード位相はscore周期でリセットしない。
包絡終了は0.19-0.21秒、評価窓の最大イベント長は0.23秒で、16分格子上の重なりと
Chapter 2より広い定位、やや高いwet sendにより、長い無音断絶を作らない。
全周期stereo RMSはChapter 2の0.85倍以上1.12倍以下、代表10秒区間は0.82倍以上
1.18倍以下とする。
固有値順序、係数比、奇偶条件、quadrature関係は変更しない。同時発音は単一モードに
限定する。DSPで採用する部分音は\(r=1\)のみで、register倍率は常に1である。
左右デチューン後の実周波数が\(0.45F_s\)未満の場合だけ生成する。
AudioWorklet設定時に周波数、定位、フォルマント重みを事前計算し、
標本ループでは時間窓内のeventだけを評価する。
Web Audioグラフはdry high-pass 220 Hz、high-shelf 1,000 Hz / -24 dB、
dry low-pass 1,080 Hz、wet high-pass 220 Hz、wet low-pass 860 Hz、
0.95秒残響、音響正規化後の出力ゲイン0.36、threshold -16 dBの圧縮、
4倍oversamplingの-1 dBFS limiterを使う。

息の粒子、六本の声部リボン、継ぎ目のシアン残光は詩的造形である。各発音モードの
局所変位、速度、継ぎ目位相から個別に応答し、同じ速度を粒子流へ渡すが、
厳密面の頂点、値、節線は変形しない。
粒子は固定seedで決定的に生成し、low 10,000、medium 22,000、
high/ultra 34,000点とする。high/ultraでは17,000点を帯近傍、7,000点を局所大気、
10,000点を全画面panoramaへ
分ける。panoramaは数学埋め込みと別のworld-space objectであり、音響と共有する
集合包絡で流速を変える。手続き生成の大気殻と6局所ハローも詩的造形として加える。

局所法線の正負方向へ同じ距離だけ離した2枚の発光シェルは詩的造形であり、
非向き付け可能なMöbius帯に対する大域的な内面・外面を意味しない。厳密面の頂点配列と
indexは変更しない。深度別環境粒子を含む総粒子予算は
`16,000 / 42,000 / 82,000 / 112,000`で、環境粒子は
`6,000 / 20,000 / 48,000 / 78,000`である。WebGL2では環境粒子の実描画上限を
8,000点にする。56.470588秒周期のカメラは最大24度の水平orbit、最大12%のdolly、
X方向10%・Y方向8%の注視点移動を行う。WebGPUとWebGL2のbloom、背景星雲、カメラも
詩的造形層であり、厳密面、境界、節線、継ぎ目、解析値ではない。
