# 視覚設計

V2現状品質版の実装方針。全章の観察結果と未測定範囲は進捗記録を参照。

## 共通言語

墨に近い黒、温かいアイボリー、酸化した金、深い緑を基調とする。
全面的なネオン、ガラスのカード、HUDへ寄せず、線、素材、奥行き、余白を使う。
主役の数学形状、発音が触れる局所、遠景の大気を分け、焦点と黒の階調を保つ。
Bloomの強さや粒子数だけを品質尺度にしない。

## 章の素材と運動

| 章 | 素材・空間 | 局所運動の語彙 |
| --- | --- | --- |
| Residue | 金属糸と薄い絹、円鎖から開く履歴 | 調波ごとの接触、残像の折り重なり。円鎖と波形を共通倍率で領域へ収める |
| Cathedral | 石英、長方形の波と垂直構造 | モード領域の短い反響 |
| Prime | 琥珀、25点の位相空間 | 素数走査、点ごとの火花と凝集 |
| Möbius | 真珠色の帯、ひねられた同一視 | 帯を渡る連続変位と流れる尾 |
| Bessel | 青磁色の円板と水盤 | 選択モードの節、同心の波紋 |
| Lissajous | 金緑の弦、閉曲線の果樹園 | 曲線上の接触と弦の残光 |
| Dirichlet | 灯芯と残火、4層の核 | 主峰と側葉の応答 |
| Wavelet | 墨と銀、支持区間の雨 | セルから落ちる係数と衝突 |
| Riemann | 銅の帳、4枚の有限曲線 | 平方数の位相と薄い余韻 |
| Torus | 緑の金属、軌道と周回空間 | 位相を巡る局所接触 |

色だけで区別せず、カメラ、密度、背景配置、瞬間応答、長周期の対比まで設計する。
近景・中景・背景・大気・数学・瞬間応答・長周期運動を持たせ、非同期の局所変化を保つ。
幕のエネルギーは演出量を変えてよいが、数学座標や係数を変えない。

## 厳密表示

Besselの節線は選択した単独モードの平面投影であり、合成面全体の節とは呼ばない。
Lissajousの平面曲線とHaarの固定支持を装飾の揺れで変形しない。
Haar再構成は半開区間ごとに一定の線分、Dirichletの正規化核は共通倍率で表示する。
Riemannの有限部分和を無限関数そのものと説明しない。
トーラスと厳密軌道には同じ剛体変換を適用する。

Cathedralは波面の正負を緑と琥珀で分け、面材質へ一律の青を掛けない。
観測点の柱を波面と同じ平面座標に置き、細い石英の殻と控えめなアーチを重ねる。
動きを抑える設定では柱の高さ、粒子、アーチ上の移動点を固定し、波面・節線と局所輝度は進める。
Möbiusは真珠色／青灰色の符号面と細い声部を重ねる。光点は進行モードの位相速度に従い、
立って振動するn=0では固定する。高次部分音重みの比を局所の色温度へ写す。
動きを抑える設定では装飾の位置・姿勢・大きさを固定し、数学と輝度を進める。
Haarは半開支持ごとの輪郭を固定し、粗い階層の塗りが細かな支持と再構成線を覆わないようにする。

数学線・文字はnative解像度を守る。ノートを開くとcanvasを再配置し、長い幅の
アニメーションでGPUの描画バッファを毎フレーム作り直さない。

WebGPUのnative Pointsは1物理pixelで、点サイズ指定による縮小が効かない。
点の面積がDPR 1で相対的に大きく見えるため、共通背景のWebGPU点、
正投影の円鎖背景のWebGL点、Residueの流れの点は0.5 CSS pixel相当の面積を基準とし、
不透明度へmin(1, DPR²/4)を掛ける。DPRの上限は2である。
粒子座標・数学線の倍率・個数はこの補正に使わない。透視投影のWebGL背景は既存の距離減衰を保つ。
Cathedralの固有粒子もWebGPUでは同じ面積補正を受ける。resize直後と局所energy更新後の
両方へ反映し、柱・アーチの光点と数学面には掛けない。WebGLの透視投影粒子は距離減衰を保つ。
Möbiusの表面・周囲・遠景の点もWebGPUでは同じ面積補正を受ける。
遠景の発音由来の不透明度更新に補正を維持し、帯の面、節線、リボン、局所ハローには掛けない。

## 観察と遷移

観察ノートの[数学実験](mathematical-exploration.md)は、固定軸、明線、淡い破線で比較する。
装飾を増やさず、操作した量と変わった結果を近くに置く。

章切替では旧章の実際の描画を短い残像として新章へ重ねる。残像は旧音声のmaster減衰と
同じ時計に従い、数学的に異なる対象を架空の補間式で変形しない。
前後の関連または対象の違いを一文で示す。次の音と光はscene準備後の共通epochから始まる。
